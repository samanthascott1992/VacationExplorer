VacationExplorer

Track your vacations, excursions, and adventures with ease.

Android Features

  • Manage vacations with start and end dates
  • Add excursions to your vacations
  • Built-in date validation and user-friendly interface
  • Search, Export, and Alert functionalities.

How to Download and Install

This app is currently available for local download only.

  1. Open the GitHub Page link: https://samanthascott1992.github.io/VacationExplorer/
  2. Scroll down to the Source Code section.
  3. Click on "Signed APK". This will take you to the GitHub repository where you will download the APK file.
  4. Tap on the file to open it.
  5. Enable Unknown Sources in Settings > Security to allow installation from non-official sources.
  6. Select Install to begin the installation process. The app will be installed on your device.

Once installed, the VacationExplorer app is ready to use, and you can start managing your travel plans!
